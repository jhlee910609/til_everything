### 2. Scalable Component Architecture
*Tech Foundation*
> 혼자서 빠른 속도로 많은 기능을 개발하기 위해 재사용성과 유지보수성이 높은 코드 베이스를 구축했습니다.

**Action (해결방안):**
*   **Design System**: Material-UI를 커스텀하여 위스터디만의 UI Kit(Input, Modal, Button 등) 구축.
*   **Pattern**: 비즈니스 로직과 뷰를 분리하는 **Container-Presenter 패턴**을 적용해 코드 가독성 향상.
*   **Reusable Logic**: 여러 페이지에서 반복되는 검색, 필터링, 페이지네이션 로직을 모듈화하여 개발 시간 단축.

**Impact (성과):**
*   **Speed**: 3주 만에 사내 Admin을 런칭하고, 4개월 만에 15개 메뉴의 CRM 솔루션 완성.
