## 기본 정보

- 재직 기간: 2019.05 ~ 2019.11 (7개월)
- 회사명: WeStudy
- 역할: Front-end Developer
- 주요 업무: 학원 관리 CRM 솔루션 프론트엔드 개발

## 성과 및 기여도

- Zero Base부터 완전한 CRM 시스템 단독 개발
- 사내 Admin과 고객용 Admin 2개 시스템 구축
- 15개 메뉴 기능 완전 구현
- Container-Presenter 패턴 적용으로 컴포넌트 재사용성 향상
- 재사용 가능한 컴포넌트 설계 및 개발 (table, pagination, 검색, 필터)
- 커스텀 Input Component 개발로 사용자 경험 향상
- B2B 학원 관리 솔루션 완전 구축
- 포인트 관리 시스템 및 세금 계산서 발행 기능으로 비즈니스 프로세스 자동화
- 영업 관리 시스템으로 영업 효율성 향상

## 주요 프로젝트 및 업무

### 1. 고객 관리용 사내 Admin 개발 (3주)

#### 역할 및 담당 업무

- 학원 지점, 학원 브랜드, 직원별 가입 시스템 구현
- 고객 가입 및 조회 기능 개발
- 영업 및 지점 현황 관리 기능 개발 (포인트 입금/차감 내역, 지점 이슈 조회, 지점명 검색)
- 영업 사원 및 에이전시의 영업 활동 조회 기능 개발
- 포인트 관리(입금에 따른 포인트 추가/차감, 포인트 사용 내역 조회)
- 세금 계산서 발행 기능 구현

#### 성과

- 내부 관리 프로세스 자동화
- 데이터 조회 효율성 향상
- 포인트 및 영업 관리 간소화

### 2. 고객용 CRM Admin 개발 (4개월)

#### 역할 및 담당 업무

- B2B 고객 대상 학원 관리 솔루션 구축
- 회원가입 및 로그인 시스템 구현, 입력 값 검증을 위한 커스텀 input component 개발
- 미입력, 적합, 부적합 상태에 따른 UI 변화 구현
- 대시보드 개발 (ReChart 라이브러리를 활용한 차트 컴포넌트, MobX 상태 관리, 기간별 데이터 조회 기능)
- 15개 메뉴 운영 화면 개발 (재학생, 직원, 학부모, 행사, 수납, 상담, 강좌 등)
- 목록(리스트) → 입력/수정 → 상세 플로우 구성
- 재사용 가능한 table, pagination, 검색, 필터 컴포넌트 개발

#### 성과

- CRM 서비스 완성도 향상
- 고객 데이터 관리 자동화
- 관리자 및 고객 편의성 개선
