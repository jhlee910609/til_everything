## 주요 프로젝트 및 업무

### 학원 관리 솔루션 Tims 개발 (2019.05 ~ 2019.11)
**Zero base부터 혼자 진행한 풀스택 프로젝트**

> 당시 회사 사정상 아래 프로젝트를 혼자 Zero base부터 진행하게 되었습니다.

#### 1. 고객 관리용 사내 Admin 개발 (3주)
**B2B 고객 및 영업 관리를 위한 관리자 시스템**

- **고객 가입 관리**
  - 학원 지점, 학원 브랜드, 직원별 분류에 따른 다른 가입 화면 구현
  - 고객 가입 및 조회 기능

![WeStudy Admin](https://tva1.sinaimg.cn/large/006y8mN6gy1g85oamnn95j30ro0fv76r.jpg)

- **지점 현황 관리**
  - 각 지점(고객)의 포인트 입금/차감 내역, 지점 이슈 조회
  - 지점명 검색 기능

- **영업 현황 관리**
  - 영업 사원 및 영업 에이전시의 영업 활동 조회

- **포인트 관리**
  - 입금에 따른 포인트 추가/차감
  - 포인트 사용 내역 조회
  - 세금 계산서 발행 기능

#### 2. 고객용 CRM Admin 개발 (4개월)
**B2B 고객을 위한 학원 관리 솔루션**

- **회원가입 및 로그인 시스템**
  - 입력 값 검증을 위한 커스텀 input component 개발
  - 미입력, 적합, 부적합 상태에 따른 UI 변화 구현

![WeStudy CRM](https://tva1.sinaimg.cn/large/006y8mN6gy1g85qtb66c1j31c80u0wh8.jpg)

- **대시보드 개발**
  - ReChart 라이브러리를 활용한 차트 컴포넌트 개발
  - MobX를 활용한 상태 관리
  - 기간별 데이터 조회 기능

![Dashboard](https://tva1.sinaimg.cn/large/006y8mN6gy1g85qtbw9xfj30vl0npabd.jpg)

- **15개 메뉴 운영 화면 개발**
  - 재학생, 직원, 학부모, 행사, 수납, 상담, 강좌 등
  - 목록(리스트) → 입력/수정 → 상세 플로우로 구성
  - 재사용 가능한 table, pagination, 검색, 필터 컴포넌트 개발

![CRM Features](https://tva1.sinaimg.cn/large/006y8mN6gy1g85qd4ufjvj30uy0jz76q.jpg)
